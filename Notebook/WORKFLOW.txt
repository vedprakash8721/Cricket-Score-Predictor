5️⃣ FEATURE ENGINEERING
Objective: Create meaningful metrics for prediction.
Feature	Description
current_score	Cumulative runs scored so far
runs_left	Remaining runs to win = Total Target − Current Score
balls_left	Remaining balls = 126 − (Over × 6 + Ball)
wickets_left	10 − cumulative dismissals
current_rr	Current Run Rate = Current Score ÷ Overs Played
required_rr	Required Run Rate = Runs Left ÷ Overs Remaining
result	Binary output (1 = Win, 0 = Loss)
All these features together form the model’s input space.
